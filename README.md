# FTracker v1.8.72 — iOS PWA optimization

Дата релиза: 03.10.2026

## Что изменено
- **Анимации упражнений вынесены из `app.js` в корневые файлы `*-N.webp` (без подпапок, для загрузки на GitHub Pages через веб-интерфейс).** Раньше ~6 МБ base64 лежали прямо в коде и разбирались при каждом запуске. `app.js`: 6,7 МБ → ~0,7 МБ. Удалены 6 дублей изображений, которые перекрывались одноимёнными ключами.
- **`styles.css`: 718 → ~555 КБ.** Удалено ~4 250 деклараций, которые гарантированно перекрыты более поздним правилом с тем же селектором. Вычисленные стили всех элементов (тёмная и светлая темы) совпадают с прежними.
- **Service Worker переписан.** Запуск из кэша без ожидания сети; картинки кэшируются лениво при первом открытии (`ftracker-media-v1`, не сбрасывается при обновлении версии); оболочка прекэшируется с обходом HTTP-кэша.
- **`index.html`:** убраны `no-cache`/`Pragma`/`Expires` (конфликтовали с офлайн-режимом), дубли мета-тегов; добавлены `apple-touch-icon.png` (180×180), `mobile-web-app-capable`, `format-detection`.
- **`manifest.json`:** убрано нестандартное `appVersion`, добавлен `lang`.
- Убрана повторная регистрация/проверка обновления Service Worker и логи в консоль.
- README очищен от истории прежних версий.

## Что не менялось
Логика тренировок, формулы Индекса, рабочий вес, таймер, формат данных и ключи localStorage/IndexedDB.

## Обновление
Новая версия подхватывается в фоне и применяется при следующем запуске приложения.

## Проверки
`node --check app.js` и `node audit-tests.js`.
